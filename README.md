# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

我想做一个给潜水店使用的气瓶充填前端系统，工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面需要有待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 技术栈

React + Vite + TypeScript

## 混气签收规则

- 空气 / 高氧 / Trimix 均按目标氧含量核对：氧含量偏差 > 1 个百分点 → 保留实测值，转入待复核。
- Trimix 额外核对氦含量：偏差 > 2 个百分点 → 同样不可签收，转入待复核。
- 双瓶组按最差单瓶状态放行；任一瓶检验过期则全组不可签收。
- 签收提交按幂等键去重：重复提交只保留首次结果，待充填队列、待复核数与单瓶历史保持一致。

核心逻辑在 `src/domain/`（纯函数，无副作用），UI 在 `src/App.tsx`。
