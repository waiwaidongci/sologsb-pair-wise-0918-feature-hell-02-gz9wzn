# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

我想做一个给潜水店使用的气瓶充填前端系统，工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面需要有待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 混气签收规则

核心逻辑在 `src/signoff.ts`（纯函数，便于测试），UI 在 `src/App.tsx`。

- **氧含量核对**：空气 / 高氧 / Trimix 均按目标氧含量核对，实测与目标偏差**超过 1 个百分点**（恰好 1.0 仍放行）→ 保留实测值，进入待复核，不能签收。
- **氦含量核对**：仅 Trimix，偏差**超过 2 个百分点**（恰好 2.0 仍放行）→ 同样不能签收，进入待复核。
- **双瓶组**：按组内最差单瓶状态放行（不可签收 > 待复核 > 已签收）；任一瓶检验过期 → 全组不可签收。检验有效期当天仍有效，次日零时起算过期。
- **重复提交**：同一充填任务只保留首次结果，重复提交原样忽略；待充填队列、待复核数、单瓶历史全部由同一份提交记录派生，天然保持一致。
